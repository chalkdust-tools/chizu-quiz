# 社会科 基礎地図トレーニング

日本地理・世界地理の基本（地図・県庁所在地・首都・地方区分・国旗など）を、
くり返し練習できる学習アプリです。中学・高校の社会科の基礎固めを想定しています。

ブラウザだけで動く静的なWebアプリです。サーバーやデータベースは使っておらず、
インターネット接続がなくても（このフォルダをそのまま開けば）動作します。

## できること

- **クイズ機能**（`index.html`）
  - 日本地図・都道府県庁所在地・地方区分／世界地図・首都・国旗の6ジャンル
  - 「今日の10問／20問」「30問」「エンドレス」「まちがえた問題だけ復習」
  - 地方・地域を複数選んで出題範囲を絞り込み可能（例：東北＋関東）
  - 難易度（やさしい／少し考える／考える）で絞り込み可能
  - 間違えた問題は自動的に少し後で再出題され、ブラウザに記録が残る
- **自習プリント作成**（`print.html`、先生向け）
  - 地方・地域を選ぶと、白地図・国旗クイズ（世界のみ）・特徴選択・○×問題つきの
    学習プリントとその解答編がその場で作られる
  - そのままブラウザの印刷機能でプリントできる

## 使い方（オフラインでそのまま使う場合）

このフォルダの `index.html` をダブルクリックしてブラウザで開くだけで使えます。
先生が自習プリントを作りたいときは `print.html` を開いてください。

## 動作環境

Windows・Chromebook・スマートフォンの主要ブラウザ（Chrome、Edge、Safari など）で
動作確認しています。特別なソフトのインストールは不要です。

## フォルダの中身

```
index.html        クイズ画面
print.html        自習プリント作成画面
style.css         共通スタイル
print.css         自習プリント用スタイル
app.js            クイズのしくみ
print.js          自習プリント作成のしくみ
data/             都道府県・国・地図データなど
assets/flags/     国旗のSVG画像
NOTICE.md         使用素材のライセンス表記
```

## 素材のライセンスについて

地図データ・国旗データは、それぞれ別のオープンソースプロジェクトの素材を
利用しています。詳しくは [NOTICE.md](NOTICE.md) を参照してください。

## 個人情報について

このアプリは個人情報を一切収集しません。「まちがえた問題」の記録は、
利用しているブラウザの中だけ（localStorage）に保存され、外部には送信されません。
