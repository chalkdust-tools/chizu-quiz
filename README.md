# 社会科 基礎力マップ

高校生向けの、地図・都道府県・世界地理の基礎反復アプリです。外部ライブラリ、ログイン、データベースは使っていません。

## フォルダ内の整理

### 1 教材サンプル

- `配布用教材/日本地図_基礎問題20問_自習課題.docx`
  - 「目標」「まず自分のこと」「やさしい問題から考える問題」「自己採点」「振り返り」を確認するためのWord教材です。

### 2 日本地図素材

- `地図素材/日本地図_都道府県境_CC0.svg` と `.png`：番号入り地図
- `地図素材/日本地図_問題用_番号なし_CC0.svg` と `.png`：白地図
- `地図素材/日本地図_都道府県別_CC0.svg`：都道府県ごとに色を付けられる地図

### 3 世界地図素材

- `地図素材/世界地図_国境入り_CC0.svg` と `.png`
- `地図素材/世界地図_問題用_白黒_CC0.svg` と `.png`

### 4 その他のデータとアプリ

- `data/prefectures.js`：都道府県、県庁所在地、地方区分
- `data/countries.js`：国名、首都、地域、国旗、地図ID
- `data/questions.js`：26種類の問題テンプレート、自習プリントの地域特徴と表示文
- `tests/quality-check.js`：選択肢の重複や正解数をまとめて確認する品質検査
- `index.html`：画面の部品
- `styles.css`：見た目とA4印刷設定
- `app.js`：クイズとプリント作成の動き
- `maps-inline.js`：ダブルクリック起動でも地図を表示するための内蔵データ
- `地図素材/出典とライセンス.md`：素材の出典

## 起動

いちばん簡単なのは、フォルダ内の `index.html` をダブルクリックする方法です。ChromeまたはEdgeで、そのまま使えます。

`start-app.cmd` をダブルクリックしても同じ画面が開きます。Pythonや黒いサーバー画面は不要です。

GitHub Pagesで公開した場合も、同じファイル一式がそのまま動きます。

## 使い方

### 地図クイズ

1. トップで「地図クイズ」を押します。
2. 「今日の10問」「今日の20問」なら設定なしで始められます。細かく選ぶ場合は、分野と10問・20問・30問・ランダム・エンドレス・まちがい復習を選びます。
3. 答えか「わからない」を押すと、自動で次へ進みます。まちがえた知識は、コースの問数を増やさず、3〜5問後を目安に別の聞き方で出ます。
4. 途中で採点するなら「ここで結果を見る」、採点せず戻るなら「やめる」を押します。

範囲を細かく絞って問題候補が少ない場合は、同じ問題をそのまま繰り返さず、作れる問数へ自動で調整して画面に表示します。地図クリック問題は地方・地域を拡大し、小さい県や国には押しやすい補助範囲を付けています。

### 自習プリント作成

1. トップで「自習プリント作成」を押します。
2. 「日本地理」か「世界地理」を選びます。
3. 日本版では北海道・東北・関東などを選びます。世界版では「世界全体」または地域を3つまで選べます。
4. 「この範囲でプリントを作る」を押します。
5. 内容を確認して「印刷する」を押します。「同じ条件でもう1枚」で、ほぼ同じ難しさの別版を作れます。

日本版はA4縦3ページ、世界版はA4縦4ページです。複数地域を選ぶと、地方・地域ごとに地図の色を分けます。日本版も世界版と同じように地図上の番号を見て県名を書きます。日本版の地方名記入欄は選んだ地方の数だけ表示されます。世界版には小さい世界全図と地域拡大図、基本6問、○×10問、解答・自己採点が入ります。日本版で都道府県を個別に選んだ場合、○×問題も選んだ県を中心に作ります。画面上のボタンは印刷されません。

## データを直す場所

- 都道府県や県庁所在地を直す：`data/prefectures.js`
- 国や首都、国旗を追加する：`data/countries.js`
- 地方の特徴を直す：`data/questions.js` の `REGION_FEATURES`
- 問題形式の一覧と難易度を直す：`data/questions.js` の `QUIZ_TEMPLATES`
- 不自然な誤答の出方を直す：`data/questions.js` の `JAPAN_REGION_CONFUSABLES` / `WORLD_REGION_CONFUSABLES`
- 問題文を作る処理を増やす：`app.js` の `makeQuestion`

既存の1行をコピーして、名前などを書き換えるのが簡単です。記号の `{ }` や、行末のカンマ `,` は消さないでください。

## 問題品質を確認する

Node.jsが入っているPCでは、このフォルダで `node tests/quality-check.js` を実行すると、全26形式の正解・選択肢重複、20問コースの連続、プリント問題の○×比率をまとめて確認できます。通常の授業利用では、この操作は不要です。

## GitHub Pagesで公開する

1. このフォルダの中身をGitHubのリポジトリへ入れます。
2. GitHubの「Settings」→「Pages」を開きます。
3. 公開元を `main` ブランチのルートにします。
4. 表示されたURLを学校PCやChromebookで開きます。

生徒の名前や回答は送信しません。まちがい復習のデータだけを、その端末のブラウザ内に保存します。
