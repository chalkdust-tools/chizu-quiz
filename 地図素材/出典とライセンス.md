# 地図素材の出典とライセンス

## 日本地図

- 素材名: `Japan prefectures.svg`
- 出典: https://commons.wikimedia.org/wiki/File:Japan_prefectures.svg
- 作者: Andreasl01（元画像 Golbez）
- ライセンス: CC0 1.0 Universal
- 本フォルダでは、教材用に黄色の塗りを白へ変更し、都道府県番号を除いた白地図版も作成しています。

### 都道府県ごとに色を付ける地図

- 素材名: `ディフォルメ都道府県日本地図`
- ファイル: `日本地図_都道府県別_CC0.svg`
- 出典: https://github.com/lalamalink/japan-map-svg
- 作者: lalamalink
- バージョン: 2026.06.30
- ライセンス: CC0 1.0 Universal
- 都道府県ごとの path に `data-code` があるため、クイズと自習プリントで選択範囲を色付き表示しています。

## 世界地図

- 素材名: `Blank map of the world.svg`
- 出典: https://commons.wikimedia.org/wiki/File:Blank_map_of_the_world.svg
- 作者: Canuckguy
- ライセンス: CC0 1.0 Universal
- 本フォルダでは、教材・モノクロ印刷用に陸地を白、国境線を黒へ変更した白地図版も作成しています。

CC0素材のため、複製・改変・再配布・教材への利用が可能です。
